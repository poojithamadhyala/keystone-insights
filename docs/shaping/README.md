# Shaping docs

One page per feature, written **before** building it (loosely following Shape Up). Each one sets:

- **Problem:** what hurts today, in the user's words
- **Who it's for:** the persona from `docs/operator-brief.md`
- **Appetite:** how much time it's worth. When it runs out, cut scope; don't extend the time.
- **Sketch:** the smallest thing that solves the problem
- **Out of scope:** what we are explicitly not doing
- **Risks / rabbit holes:** where time could disappear, and the plan for each
- **Go / no-go:** what must be true to ship. If it isn't, cut it or reshape.
